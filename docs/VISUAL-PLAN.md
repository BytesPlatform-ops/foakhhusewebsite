## Ambient colour system

Backgrounds are environmental light, not flat fills. Adjacent sections
share a 20–35% viewport gradient overlap (`.blend-top` utility) so no hard
colour cuts occur. Saturation stays restrained; accents (cyan, champagne,
orchid, amber) appear only as travelling events on routes, scans and pulses.
